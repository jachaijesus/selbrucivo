# Emergent.ai First Iteration Archive

This folder preserves the Emergent.ai first iteration of Selbrucivo as historical production prototype material.

It is not the current canonical application.

## Purpose

This archive exists so the early production prototype, backend/frontend structure, metadata, and reports remain available for reference while keeping the Phase 4D.5 Vite/React app clean at the repository root.

## Contents

- `frontend/`: archived Emergent.ai frontend prototype
- `backend/`: archived Emergent.ai backend prototype
- `metadata/emergent.yml`: archived Emergent.ai project metadata
- `reports/`: archived test/report material associated with the prototype

Generated cache material, local machine configuration, credential files, token files, environment files, nested Git repositories, and the duplicate Vite app folder are intentionally excluded.

## Current Development

Current Selbrucivo development should happen in the repository root app, not inside this archive. Treat this directory as read-only historical reference unless a future migration plan explicitly says otherwise.
