# Selbrucivo

This repository's root contains the current canonical Selbrucivo application: the Phase 4D.5 Vite/React interactive sphere app.

## Current App

- Active app location: repository root
- Framework: Vite, React, TypeScript
- Primary source: `src/`
- Build command: `pnpm run build`

The root app is the implementation that should be used for current development and future Phase 4E work.
